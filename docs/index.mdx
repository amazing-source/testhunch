testhunch lit les rapports **JUnit XML** que votre lanceur produit déjà, plus `git diff`. Rien
d'autre. C'est pour ça qu'il n'est lié à aucun langage : il est testé sur de vrais rapports de
pytest, Vitest, Jest, Go (gotestsum), Java (Maven Surefire) et Rust (cargo-nextest).

<Note>
**Statut : pré-alpha.** L'ingestion, le stockage, les rapports et un classement explicable
fonctionnent aujourd'hui, et un benchmark public les mesure. Le modèle appris viendra plus tard. Il
ne sera livré que s'il bat l'heuristique actuelle, et la comparaison sera publiée dans les deux cas.
</Note>

## Ce qu'il fait

1. **`ingest`** enregistre, après votre job de tests, le résultat de chaque test pour ce commit et
   les fichiers modifiés.
2. **`report`** montre les tests instables (réussis *et* échoués sur le même commit), les plus lents
   et ceux en échec.
3. **`prioritize`** ordonne les tests pour le changement en cours, et explique chaque place.
4. **`shadow`** mesure ce que sauter des tests *aurait* manqué, avant qu'on saute quoi que ce soit.

## Sur les chiffres

testhunch n'avance pas de promesse de précision sans la mesure qui va avec. Les résultats sont
publiés projet par projet, **y compris là où testhunch s'en sort mal**. Ils sortent de commandes du
dépôt, ils ne sont pas écrits à la main :

- [Résultats du benchmark](https://github.com/amazing-source/testhunch/blob/main/benchmarks/results/README.md),
  20 projets Java sur de l'historique Travis CI réel, plus quatre projets rejoués commit par commit ;
- [L'étude du classement](https://github.com/amazing-source/testhunch/tree/main/benchmarks/results/study),
  comment cette version a été choisie et ce qu'elle vaut face à « les tests qui ont échoué le plus
  récemment d'abord » ;
- [Les décisions d'architecture](https://github.com/amazing-source/testhunch/tree/main/docs/adr),
  pourquoi les choses sont faites ainsi, y compris ce qui a été écarté.

Ce site ne recopie aucun de ces chiffres, il y renvoie. Un nombre mesuré vit dans un seul fichier,
celui qu'écrit la commande qui l'a calculé
([ADR 0019](https://github.com/amazing-source/testhunch/blob/main/docs/adr/0019-the-documentation-site-carries-no-number-of-its-own.md)).
